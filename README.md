# Huduma Campus ? Student Support & Inquiry Management System

A PHP (PDO) and MySQL web portal for managing student inquiries, departmental SLAs, and audit logs.

## Tech Stack
- **Backend:** Core PHP 8+ with PDO Prepared Statements
- **Database:** MySQL (`huduma_campus_db`)
- **Frontend:** Semantic HTML5 & Responsive CSS3 (Light/Dark cookie theme)

## Setup Instructions
1. Start **Apache** and **MySQL** in XAMPP.
2. Import `sql/database.sql` into MySQL.
3. Access `http://localhost/huduma_campus/` in your browser.
